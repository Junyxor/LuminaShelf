# 0.7 人工核查范围

构建、接口、文件转换、持久化和无窗口 UI 检查由脚本验证；以下项目需要设备、系统应用或真实账户。
不能以编译通过或桌面测试代替这些结果。

1. 使用原签名在 Android 上覆盖 0.6，确认书架和阅读进度保留，原有自定义 DNS 自动进入配置列表。
2. 在手机网络/Wi-Fi 下添加自己的完整 DoH URL，分别测试留空、单个和多个引导 IP，关闭回退时确认真正使用该服务。
3. 使用自己的 Z-Library 账户核查登录、配额、下载描述符/真实文件、实际文件大小与打开阅读；不向测试人员提供密码。
4. 下载原格式与站点真实提供的其他版本；站点缺少格式时保持缺失，不生成虚假转换选项。
5. 长按文件，在已安装阅读器中打开 EPUB/PDF/MOBI；返回星书后阅读进度仍可继续。
6. 点击系统分享，手动选择邮箱/云盘应用，确认附件可读。未安装目标应用、未登录云盘等状态应由系统应用正常提示。
7. 使用 Android 文档提供方导出，包含本机目录和已连接云盘；取消保存不应删除原文件。
8. TXT ↔ EPUB 转换保留中文、段落和章节文字；转换说明已明确图片/排版不保留。PDF/OCR/任意格式互转未实现。
9. 分别检查“从书架移除”和“删除下载文件”：前者保留文件，后者只删除应用管理的副本，远程收藏保留。
10. 书源公告为空、官网验证页、GitHub 无 Release 和限流都必须显示真实状态。没有核实活动链接时，不展示假捐赠活动或支付地址。

官方账户转码、邮件、Kindle、Google Drive 的具体远端动作尚未进行真实账户验证，
当前通过用户明确点击的官网入口使用。应用自己的 Android 系统分享与本地转换是独立能力。
